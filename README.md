# Ancestry-to-WebTrees
Author W. Mantz  July 2026

GED File Conversion Utility from Ancestry GED to WebTrees Generic GED

This utility is a simply python script that converts the exported ancestry.com gedcom file format to a generic format for WebTrees.

Note:  There are limitations of the ged file for data sources, such as images, documents and such that you would find on Ancestry.com 
because of their proprietary format.   The reference will be in the ged file but it will not be a click event. 
python 3.12 or higher

usage:  python ancestry-to-webtrees.py

it will prompt for input and output files where the output file is cleaned ged filename.
